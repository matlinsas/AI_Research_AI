测量口径

  • NVIDIA B300 SXM6 AC, 10.3, 620.70.06，CUDA 13.1.1，sm_103a。记录 9 次独立计时的中位数，使用同一个 SM cycle 区间计算各分项。
  • TMA 用 cp.async.bulk.tensor.2d.global.shared::cta.bulk_group 从 SMEM 读数据并存入 global。用 wait_group.read 0 记录源端完成，再单独等待完整写入。
  • 普通 dense MMA 的 A、B 都从 SMEM 读取，使用 collector discard。SMEM 小计含 LDS、MMA A/B、CP 和 TMA；合计再加上 LDG 流量，包括 L1 miss 的读取。
  • 31 组均通过 Nsight 指令和流量核对。五路配置通过 memcheck 和 racecheck。图表使用无 profiler 的计时，表中的 L1 命中率来自另一次计数器采集。
