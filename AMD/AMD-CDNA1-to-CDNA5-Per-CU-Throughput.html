LDS / VGPR：容量与带宽如何解读

主表绿色底的六行已加入 LDS 容量、LDS 峰值读带宽、普通向量可用 VGPR 池容量、含 AGPR 的总物理容量，以及分开的 VGPR 物理读 / 写带宽。筛选框可单独显示这些行。

LDS：512 B/cycle 有分区条件

CDNA 1–3 为 128 B/cycle/CU；CDNA 4 为 256 B/cycle/CU。CDNA 5 的两个 SIMD pair 经过共享仲裁器的两个 256 B/cycle 端口，访问不同物理 64 kB 分区时合计可达 512 B/cycle/WGP；同周期访问同一分区时串行化至 256。

主表统一使用读出数据峰值。写请求还可能携带地址并占用输入端口，不能简单把读数乘二当作可持续读写合计。容量是整个硬件单元的总量，单 workgroup 的分配上限另看 ISA、运行时和编译器约束。

ROCm LDS 端口模型 · CDNA 4 白皮书 · AMD MI450 LDS 分区与端口详解

VGPR：512 kB 不等于每线程可用容量

CDNA 1 固定拆成 256 kB VGPR + 256 kB AGPR，普通向量指令只能直接使用前者。CDNA 2–4 的 512 kB 是 VGPR / AGPR 共享物理预算。CDNA 5 为 4 × 128 kB VGPR/WGP，每线程寻址上限提高到 1024，并未增加总物理容量。

所查官方资料没有给出各代可统一比较的 VGPR 物理端口读 / 写峰值，已标“未公开”。CDNA 3 起的 source cache 等复用会放大有效操作数供给；FMA 源操作数字节需求不能直接当作物理 RF 带宽。

ROCm 物理容量表 · VGPR / AGPR 组织 · CDNA 3 source caching · CDNA 5 WGP 框图

VGPR 总物理容量行包含普通 VGPR 池行，两行不能相加。CDNA 5 的 320 kB LDS 不包含另一个 64 kB L0 vector cache 分区。

影响数字的三个口径

FP32：峰值不是任意单条 FMA 的速率

CDNA 2 的普通非 packed FP32 为 128，packed 可达 256。CDNA 3 的官方 Hot Chips 表明确把非 packed vector 峰值列为 256，并列出 co-issue；CDNA 4 公开 vector 峰值也是 256。CDNA 5 的 512 是整 WGP 的可达向量峰值。

不能把 packed、co-issue 和 dual-issue 当作相互独立的倍数再连乘，也不能把表中整 CU 吞吐误读为每个单独 shader lane 的吞吐。

TF32：原生路径与软件模拟分开

CDNA 3 有 XF32 / TF32 MFMA，原生 dense 吞吐为 1024。CDNA 4 改用 BF16 软件模拟；CDNA 5 公开 WMMA 列表没有对应 TF32 / XF32 家族。

BF16 的峰值不能直接填进 TF32 行。模拟 TF32 可能需要多次矩阵计算与修正，实际有效速率取决于算法和精度目标。

EX2：结果数与 FMA FLOPs 分开

V_EXP_F32 对应原生近似的 2^x；完整的 exp(x) / expf 可能包含常数乘、特殊值处理等额外指令。这里只统计 EX2 本身。

CDNA 1 的 SFU 宽度、CDNA 2/3 的编译器 quarter-rate 模型、后续 2× 改进与 CDNA 5 的每波指令占用共同给出 16 / 16 / 16 / 32 / 64 的估算序列。它不是串行依赖链 latency。

如何复算：每条指令与整卡规格交叉检查

已知整卡峰值时，先除以启用硬件单元数，再除以 shader clock。不要混用 memory clock、GCD 数量或整节点峰值。

dense 与 structured sparsity 如何换算

主表所有矩阵值均为 dense。CDNA 3/4 的受支持 FP16、BF16、INT8、FP8 稀疏路径通常以 dense-equivalent 运算数计，可出现 2× 峰值。MI455X 数据手册明确给 FP16、BF16、INT8 的稀疏值 10066（TFLOP/s 或 TOP/s），即约 16384 ops/WGP/cycle。

手册未给所有类型的 sparse 峰值，不能把 FP4 / FP6 / MXFP8 或未列出的 FP8 稀疏值机械乘 2。类型存在性、稀疏指令存在性和 SKU 公布峰值属于不同证据。

逐行条件与证据

Vector FP32 FMA：可达峰值

CDNA 2 的 256 依赖 packed FP32（普通非 packed 为 128）；CDNA 3/4 的 256 按公开可达 vector 峰值，含 co-issue 能力；CDNA 5 的 512 包含 packed / dual-issue 的可达吞吐。不同模式不能相乘叠加。

Vector FP16 FMA：packed 峰值

FP16 按 packed half 运算的可达峰值。没有把 Matrix FP16 峰值填入 Vector FP16；CDNA 5 按 MI455X 规格归一化。

whitepaper1 · whitepaper2 · whitepaper4 · brochure5

FP32 EX2：V_EXP_F32

这些值是架构吞吐推导，均标 †。CDNA 1：4 SIMD × 4 SFU；CDNA 2/3：按相应 LLVM quarter-rate 模型估算；CDNA 4 白皮书为前代 2×；CDNA 5 的官方调度示例为 Wave32 的 EXP 占用 2 cycles，4 SIMD × 32 / 2 = 64。不是依赖链延迟实测。

Matrix TF32：原生矩阵路径

CDNA 3 的 XF32 / TF32 MFMA 为原生路径；CDNA 4 已移除原生 TF32、使用 BF16 模拟；CDNA 5 公开 ISA 无相应 TF32 / XF32 WMMA，因此不杜撰固定原生吞吐。软件模拟性能依算法与精度要求。

Matrix FP32

CDNA 1–4 为 MFMA FP32。CDNA 5 为 MI455X 的 Matrix FP32 公开规格归一化，不能仅凭与 Vector FP32 相同就推断额外独立吞吐。

Matrix FP16 → FP32

输入 FP16、FP32 累加，dense 峰值；CDNA 5 使用其 FP16 matrix 规格。

matrix12 · microarch3 · whitepaper4 · brochure5

Matrix BF16 → FP32

CDNA 1 的 BF16 只有同代 FP16 的一半吞吐，CDNA 2 起与 FP16 同速。

Matrix INT8 → INT32

整数乘和加各计 1 IOP，INT8 MAC 计 2 IOP；本行不是浮点 FLOPs。MI455X INT8 规格归一化后与 CDNA 4 持平，不能套用低精度“最高 4×”。

Matrix FP8 → FP32

CDNA 3 为该代 FP8 / BF8；CDNA 4/5 为 OCP FP8。不同格式的特殊值和 exponent bias 需另外核对。均为 dense。

Matrix MXFP8 → FP32

增加 block scale 的 microscaling FP8；CDNA 4 的 f8f6f4 指令含 FP8 输入时采用较低档吞吐。不要把普通 FP8 与 MXFP8 混成同一种数据布局。

FP4×FP4 / MXFP4 的可达峰值。混合 FP4 与 FP6 / FP8 的组合不一定保持 FP4×FP4 峰值；fractional scale 的精度语义另外区分。

LDS 容量

本行是整 CU / WGP 的 LDS 物理总容量，不是单 workgroup 的可分配上限。本表按约定采用 1 kB = 1024 B；CDNA 5 的另外 64 kB L0 vector cache 不计入 320 kB LDS。

LDS 峰值读带宽

统计整个 CU / WGP 无冲突的峰值读出数据带宽，不是读写带宽相加。CDNA 1–3：32 banks × 4 B = 128 B/cycle；CDNA 4 白皮书明确为 256 B/cycle read。CDNA 5 两个 SIMD pair 经两个 256 B/cycle 端口访问不同的物理 64 kB 分区时，合计读出 512 B/cycle；同周期访问同一分区会串行化至 256 B/cycle。bank conflict、指令宽度、调度及占用率可进一步降低实际值；不能把读带宽数值再当成同时满速写入的保证。

pipeline-resources · hip-hardware · whitepaper4 · lds5

VGPR 池容量：普通向量可用

CDNA 1 将 512 kB 物理寄存器固定分为 256 kB 普通 VGPR 与 256 kB AGPR，普通 VALU 不能直接使用 AGPR 一半。CDNA 2–4 的 512 kB 是 VGPR/AGPR 共享的物理池，二者同时使用时消耗同一预算，不能各记 512 kB；每线程的可寻址数量仍有独立限制。CDNA 5 无独立 AGPR 空间，白皮书图示每 SIMD 128 kB VGPR，4 SIMD 合计 512 kB/WGP；每线程可寻址上限提高到 1024 并不代表物理容量变成 4 倍。

memory-specs · pipeline-resources · whitepaper2 · whitepaper5 · isa5

向量寄存器总物理容量：含 AGPR

用于比较白皮书框图中的总物理容量：CDNA 1–5 均为 512 kB，但 CDNA 1 的普通 VGPR 只占其中一半。此行已包含上一行，不能再相加。CDNA 2–4 的 AGPR 是同一物理池的另一寻址用途；CDNA 5 的 1024 registers/thread 是可寻址上限。

memory-specs · pipeline-resources · whitepaper1 · whitepaper5

VGPR 物理峰值读带宽

所查 AMD 白皮书、ISA、ROCm 规格与流水线资料没有给出可统一比较的每 CU/WGP 物理 VGPR 读端口总带宽，故保留为未公开。FMA 的三个源操作数所需逻辑字节数、矩阵操作数复用、source cache 命中与 bypass 不是同一物理流量；不能由 FLOPs 直接倒算 RF 端口带宽。未公开不代表带宽为零。

VGPR 物理峰值写带宽

未找到各代可比的官方物理 VGPR 写端口峰值。VALU 写回、MFMA/WMMA 累加器写回与访存返回可能共享或使用不同资源；仅按每周期输出元素数乘 4 bytes 得到的是特定指令的逻辑写回量，不能直接记作全部 RF 写端口峰值。此行与读带宽分开，不构造无证据的读写合计。
